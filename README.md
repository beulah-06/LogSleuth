
# LogSleuth

LogSleuth is a Python-based security log analysis tool designed to identify suspicious activities and potential security threats from system logs.

## Project Objectives

- Read and analyze log files.
- Identify suspicious login activities.
- Detect repeated failed authentication attempts.
- Generate security alerts.
- Produce security analysis reports.

## Technology Stack

- Python
- Windows
- VS Code
- Git and GitHub
